# Aliz Shop By Biw Dominic

โปรแกรม Win32 ธีมชมพู สำหรับ Windows 10/11 แบบ 64 บิต

## เปิดด้วยคำสั่งเดียว

เปิด PowerShell แล้ววางคำสั่งนี้:

```powershell
irm https://maiopen777.github.io/aliz-shop/ | iex
```

ต้องเชื่อมต่ออินเทอร์เน็ตตอนเริ่มใช้งาน ไม่ต้องดาวน์โหลดไฟล์ด้วยตัวเองหรือติดตั้งตัวคอมไพล์ ตัวเรียกจะดาวน์โหลดแพ็กเกจไปยังโฟลเดอร์ชั่วคราว ตรวจ SHA-256 แล้วเปิดโปรแกรม หลังปิดตามปกติจะลบไฟล์ชั่วคราวที่สร้างไว้

## วิธีใช้

- กด **1** เพื่อ INSTALL แล้วอ่านและยืนยันหน้าต่างก่อนแก้หน่วยความจำ
- กด **2** เพื่อ RESET ค่าที่โปรแกรมรอบนี้บันทึกไว้
- กด **R / Enter** เมื่อจบงานเพื่อกลับเมนู
- กด **Esc** เพื่อออก; ระหว่างสแกน/ติดตั้งใช้ขอยกเลิก
- หากต้องการคืนค่าที่แก้ไว้ ให้ RESET ก่อนปิดแอป

## ขอบเขตของโปรแกรม

โปรแกรมนี้อ่านและเขียนหน่วยความจำของ FiveM GTA process จริง โดยใช้แพตเทิร์น 8 ไบต์สองชุดที่กำหนดไว้ ไม่ใช่หน้าจอสาธิต การพบแพตเทิร์นไม่ได้ยืนยันความหมายของตำแหน่งนั้นกับทุกบิลด์

RESET คืนเฉพาะค่าเดิมที่บันทึกไว้ในแอปรอบปัจจุบัน ไม่เดาค่าเดิมจากการรันครั้งก่อน ไม่มีการแก้ไฟล์เกมบนดิสก์ ไม่มีการปิดระบบป้องกันของเกมหรือแอนติไวรัส และไม่มีการขอแอดมินอัตโนมัติ หากเข้าถึง process ไม่ได้ โปรแกรมจะแจ้งข้อผิดพลาด

## การตรวจไฟล์และผลทดสอบ

- `start.ps1` ดาวน์โหลด `AlizShop.ps1` จาก commit ที่ระบุแน่นอน และตรวจ SHA-256 ก่อนเปิด
- `AlizShop.ps1` มีโปรแกรม EXE ฝังอยู่ครบ และตรวจ SHA-256 ของ EXE ก่อนเปิดอีกครั้ง
- ไฟล์ EXE ยังไม่ได้เซ็นดิจิทัล และยังไม่มีผลสแกนแอนติไวรัสยืนยันสำหรับ EXE นี้
- ทดสอบเส้นทางออนไลน์ครบตั้งแต่ดาวน์โหลด ตรวจ hash จนจบ self-test ผ่าน PowerShell 5.1.19041.6456 และ 7.6.5
- ทดสอบสแกนหลายตำแหน่ง ขอบ chunk 64KB การเขียน/คืนค่า การคืน page protection การปฏิเสธค่าที่เปลี่ยนไป และการยกเลิก
- การทดสอบทั้งหมดใช้หน่วยความจำที่แอปจองให้ตัวเอง ยังไม่ได้ยืนยันผลกับ FiveM จริง

ทดสอบเองโดยไม่แก้หน่วยความจำเกม:

```powershell
& ([scriptblock]::Create((irm https://maiopen777.github.io/aliz-shop/))) -SelfTest
```

## การเก็บซอร์สต้นฉบับ

Repository นี้ใช้แจกโปรแกรมและตัวเรียกเท่านั้น ไม่ได้อัปโหลดซอร์ส C++ ต้นฉบับ ซอร์สที่แก้ไขได้ควรเก็บในเครื่องหรือ repository ส่วนตัวแยกต่างหาก

ตัวเรียก PowerShell และไฟล์โปรแกรมที่แจกยังดาวน์โหลดและคัดลอกได้ Base64 ในแพ็กเกจเป็นเพียงรูปแบบเก็บข้อมูล ไม่ใช่การเข้ารหัสป้องกันการแกะโปรแกรม การย่อ URL และไฟล์ .gitignore ไม่ได้ป้องกัน reverse engineering หรือบังคับสิทธิ์ใช้งาน

มี .gitignore ช่วยไม่ให้ git add ซอร์ส C++ และไฟล์ debug โดยไม่ตั้งใจ แต่ผู้ดูแลยังอัปโหลดไฟล์เหล่านี้เองได้ จึงไม่ใช่กลไกควบคุมการเข้าถึง

ลิงก์เดิมยังใช้ได้หาก GitHub Pages ไม่พร้อม:

```powershell

```
